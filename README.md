# netkit

ACL を書くときと、コンフィグを比べるときの小さな道具です。
**計算はすべてブラウザの中で行い、貼った内容はどこにも送信しません**（ページ側で通信を禁止しています）。

## できること

| 機能 | 内容 |
|---|---|
| CIDR → ワイルドカード | 貼ったテキストの `a.b.c.d/nn` の部分だけをワイルドカード表記に置き換えます。ほかの文字は変えません。`/32` → `host`、`0.0.0.0/0` → `any` にもできます |
| 範囲を調べる | `172.16.0.0 0.0.31.255` や `192.168.10.0 255.255.254.0` の範囲・アドレス数・CIDR を表示します。不連続なワイルドカードも判定します |
| コンフィグ差分 | 行の並び順ではなく、**どのセクションの、どの設定が変わったか**で比べます。Cisco IOS 系と FortiGate に対応 |

## 使い方

ページを開くだけです。インストールやログインは要りません。

ローカルで使う場合は `index.html` をブラウザで開いてください。

```bash
node test.js   # 計算部分のテスト
```
